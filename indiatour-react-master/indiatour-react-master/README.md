# IndiaTour Frontend

React frontend for the IndiaTour project. For backend and database setup, see the [backend README](../../indiatourjava-master/indiatourjava-master/README.md).

## Requirements

- Node.js and npm
- The Spring Boot backend and MySQL database running locally for API-backed pages

The frontend currently sends API requests to `http://localhost:8080`.

## Setup

Open a terminal in this directory and install dependencies:

```powershell
npm install
```

Start the development server:

```powershell
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Useful Commands

```powershell
npm test
npm run build
```

`npm test` starts the test runner. `npm run build` creates a production build in `build/`.
